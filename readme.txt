这个demo主要是用于用户输入其学习资料，我们的软件给其生成练习题的一个功能，我选择的学习资料是一份考研数学一的学习资料进行测试。

首先，对于用户上传到学习资料pdf格式的，我们首先对于pdf进行文字提取，并将其转化为Markdown，Markdown的好处在于能够进行严格等级划分，我们将学习资料中的一级标题设置为md的二级标题，将二级标题设置为md的三级标题，这样我们在划分章节的时候就以二级标题作为章节划分依据，划分更加细粒度的知识点就以三级标题作为划分依据。

后续我们需要使用大模型进行辅助，为了减少大模型的幻觉，并且能够更加有针对性，我们找到了一份考研数学大纲，这样一来就有了参考，另外如果大纲发生变化，我们只需要更新大纲即可（借鉴RAG思想）。

另外关于考试大纲，我们应该建立一个考试大纲数据库，无需用户上传，而是我们在数据库中寻找与用户上传学习资料相匹配的大纲，因此大纲的md只用生成一次就可以存在数据库中，并且由于视觉文字提取pdf可能存在误差，我们还可以对于录入数据库的大纲进行手动修改。

接下来，我们基于刚才的markdown进行章节划分以及更加细粒度的知识点划分，方便之后对于知识点进行等级评定。

然后，基于学习大纲生成的知识点，进行其掌握程度汇总（'会'、'掌握'等），基于此进行大纲中所有知识点等级评定（类似于RAG思想），得到知识点与掌握程度的对应关系json

接下来，基于知识点掌握程度进行 K-means 聚类定级,将学习资料与大纲进行语义匹配，得到学习资料中知识点的等级(学习资料内容可能会和大纲的表述有出入，因此需要这个匹配，那为什么让大模型不基于大纲直接出题呢，因为我们还需要一份学习资料中的内容来进行参考，也是类似RAG的思想)
